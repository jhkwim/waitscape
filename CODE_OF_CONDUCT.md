# 행동 강령 / Code of Conduct

이 프로젝트는 [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)을 따릅니다.
This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

서로 존중하고, 사람이 아니라 코드와 아이디어를 이야기합시다.
Be respectful; discuss code and ideas, not people.

## 신고 / Reporting

행동 강령 위반은 공개 이슈에 쓰지 말고 비공개로 알려 주세요:
- GitHub 비공개 신고(private vulnerability reporting): [Security → Report a vulnerability](https://github.com/jhkwim/waitscape/security/advisories/new)에 제목을 "행동 강령 / Code of Conduct"로 적어 보내 주세요. 메인테이너만 봅니다.
- 또는 메인테이너 GitHub 프로필([@jhkwim](https://github.com/jhkwim))에 안내된 연락 방법.

보안 문제는 [`SECURITY.md`](SECURITY.md)를 따릅니다.

Do not report violations in public issues. Report privately via GitHub private vulnerability reporting
([Security → Report a vulnerability](https://github.com/jhkwim/waitscape/security/advisories/new), title it "Code of Conduct"; only the maintainer can see it),
or via the contact options on the maintainer's GitHub profile ([@jhkwim](https://github.com/jhkwim)). For security issues, see SECURITY.md.
